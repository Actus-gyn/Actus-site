# Actus Site

Landing page pública e comercial da Actus.

## Stack

- React
- TypeScript
- Vite

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run build
```

## Identidade visual

A página reutiliza a logo oficial e os tokens consolidados nos produtos Actus:

- `#10252D` / `#1A343F` para fundos
- `#CBFE00` para ações primárias
- Barlow Condensed para títulos
- Barlow para texto
- Share Tech Mono para dados e rótulos técnicos

## Movimento

- Parallax sutil com resposta ao cursor
- Objetos de produto flutuantes
- Ecosistema completo para personal trainer e aluno
- Demonstrações navegáveis do dashboard, editor de treino e gestão de alunos
- Jornada conectada do convite à evolução
- Cena fotográfica para reforçar a presença humana
- Desafios, ranking e sequência do aluno
- FAQ interativo
- Reveals progressivos por scroll
- Fallback completo para `prefers-reduced-motion`
